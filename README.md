# 🎮 Simon Says Game

A simple Simon Says Game built using **HTML, CSS, and JavaScript**. Test your memory by repeating the color sequence correctly. The sequence gets longer with each level, making the game more challenging.

## 🌐 Live Demo Link

[Live Demo](https://simon-says-game-075664.netlify.app)

## 🚀 Features

- Random color sequence generation
- Multiple levels
- Flash animations
- Game Over detection
- Restart by pressing any key

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
├── index.html
├── style.css
├── app.js
└── README.md
```

## ▶️ How to Play

1. Press any key to start.
2. Watch the flashing color.
3. Repeat the sequence by clicking the buttons.
4. Continue to the next level by repeating the full sequence.
5. A wrong click ends the game.
